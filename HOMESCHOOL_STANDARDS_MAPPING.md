# Homeschool Standards Mapping — the Credibility Layer

**Why this exists:** homeschool families buying history curriculum ask three things — *Is it rigorous? Will it prepare my kid for college / the AP exam? Does it satisfy my umbrella school or state requirements?* This app's answer ("your kid reads the actual Declaration and Douglass and forms their own judgment") is the *selling* point — but families still need to know it **counts.** This document is that proof: each chapter mapped to the national frameworks that signal rigor. Attach it to the pitch.

## The frameworks that matter (and why homeschool cares)

| Framework | What it is | Why it sells to homeschool |
|---|---|---|
| **AP U.S. History (APUSH)** — College Board | 9 chronological periods + 8 spiraling themes | The gold standard for "college-prep rigor." Parents aiming at the AP exam / selective colleges want this alignment. |
| **C3 Framework** — NCSS | 4-dimension *inquiry* model (ask questions → apply concepts → evaluate sources → communicate) | The app's method **IS** C3 — primary-source inquiry, not memorization. This is the strongest alignment story we have. |
| **Common Core ELA — Reading in History/Social Studies (RH.6–12)** | Literacy standards: cite textual evidence, analyze primary sources, distinguish fact from reasoned judgment, corroborate sources | Umbrella schools and many state portfolios require CCSS literacy. Reading primary documents *is* this standard, exercised directly. |
| **Classical / Charlotte Mason** (not a standard — a movement) | "Living documents" over textbooks; original sources over summaries | A large, motivated homeschool subculture built on *exactly* this philosophy. Targeted marketing wedge, not a compliance box. |

## The honest note on *state* standards
Do **not** print specific state-standard codes (Texas TEKS §113.x, Florida benchmarks) you haven't verified — that's the exact "make it up to sound official" move this whole app exists to reject. Map to the **national frameworks above** (verifiable, and they carry more weight anyway), and for any state that matters to a customer, do the mechanical match against that state's **published** social-studies standards: line up by era + skill, cite the real code. Source: each state DOE's standards site. This is a per-customer add-on, not a blocker.

## How to use this in the pitch
Lead with the *experience* ("your child reads the actual documents and judges for themselves"), then close with the *credibility* ("and it aligns to AP U.S. History, follows the C3 inquiry framework, and exercises Common Core historical-literacy standards — [see mapping]"). For the classical/Charlotte Mason crowd, skip the standards talk and lead with **"living documents, not textbook summaries"** — that's their language, and this app was built in it.
